02 · STANDARDIZATION

Why unit-free coordinates matter

Without rescaling, Euclidean distance is dominated by high-variance variables (income, gdpp). Standardization centers and rescales each column to unit marginal variance — the cloud remains anisotropic in the joint sense.

X̃ᵢⱼ = ( Xᵢⱼ − μ̂ⱼ ) / ŝⱼ   →   mean = 0, variance = 1 for every column μ̂ⱼ = sample mean, ŝⱼ = sample std (ddof=1). After standardization, Cov(X̃) = Corr(X) — the correlation matrix.
Important: Standardization equalizes marginal variances, but the joint data cloud remains anisotropic — off-diagonal correlations persist. The total variance becomes exactly p = 9 (= trace of the correlation matrix), but PCA still finds strongly elongated directions. This is precisely why λ₁ = — ≫ 1.

03 · CORRELATION MATRIX

The shape of the standardized data cloud

After standardization, Cov(X̃) = Corr(X) — the correlation matrix R. This is the matrix we decompose in PCA. Each off-diagonal entry rⱼₖ = Pearson correlation; each diagonal entry = 1; trace(R) = p = 9.

R = (n−1)⁻¹ X̃ᵀX̃  ·  R ∈ ℝ⁹ˣ⁹  ·  Symmetric, PSD  ·  diag(R) = 1  ·  trace(R) = — Note: R is the covariance matrix of standardized data, and simultaneously the correlation matrix of raw data. These are the same object — distinct from the raw covariance matrix Σ = (n−1)⁻¹ XᵀX, which we do not use here.
CORRELATION HEATMAP — R = Corr(X) = Cov(X̃)
Geometric reading: rⱼₖ = cos(θⱼₖ) where θⱼₖ is the angle between the mean-centered, unit-norm column vectors x̃ⱼ/‖x̃ⱼ‖ and x̃ₖ/‖x̃ₖ‖ in ℝ¹⁶⁷. This is not the angle between standardized columns, which differ by a factor of √(n−1) from unit-norm vectors.
04 · EIGEN-ANALYSIS

The spectrum of R

R = VΛVᵀ. Eigenvalues λₖ are the variances of the data along the principal axes; their sum equals p = 9. All eigenvectors are unit-norm and mutually orthogonal: VᵀV = VVᵀ = I₉. The decomposition is computed here with cyclic Jacobi rotations: repeatedly zero the largest off-diagonal entries with 2×2 rotations until R is diagonal.

R = V Λ Vᵀ  ·  VᵀV = I₉  ·  Λ = diag(λ₁ ≥ λ₂ ≥ … ≥ λ₉ > 0)  ·  Σλₖ = 9 Checked at load time on the computed V and Λ (see the verification line below).

07 · VARIABLE LOADINGS

Eigenvector components — which variables drive each PC?

Loadings are the components of unit eigenvectors vₖ. Each loading vᵢₖ is the cosine of the angle between variable i and PC axis k. All loading vectors satisfy ‖vₖ‖ = 1 and vⱼᵀvₖ = 0 (j ≠ k).

Sign note: Eigenvector signs are arbitrary — only the direction (axis) is determined, not the orientation. Here, signs are fixed by convention: the variable with the largest absolute loading on each PC is set positive.
